# 工作日志 Skill

**skill_id**: `work-logs`
**版本**: 1.1.0
**output_dir**: `docs/work-logs/`

---

## 1. 概述

本技能定义 AI Agent 记录工作日志的标准流程。日志的目的是**解决问题**和**传承知识**，不是填表格。

### 1.1 触发条件

| 触发方式 | 条件 |
|----------|------|
| 自动触发 | 每次完成任务后，AI 助手必须执行本 Skill |
| 显式触发 | 用户指令包含关键词：`日志`、`记录`、`work log` |

### 1.2 前置依赖

| 依赖 | 用途 | 必要性 |
|------|------|--------|
| 网络时间查询 | 获取中国上海时间 | 必需 |
| view 工具 | 读取已有日志文件 | 必需 |

### 1.3 关联规范

详细模板、字段、标签、状态、日志结构与自检要求详见：[SPEC.md](./SPEC.md)

为什么：`SKILL.md` 负责定义触发条件、执行流程和强制行为；日志模板、字段标准和结构约束应由 `SPEC.md` 统一维护，避免入口说明和模板细则混写后失去可预测性。

---

## 2. 执行流程

```
1. 获取当前北京时间（精确到秒）
   |
2. 确定日志文件路径：docs/work-logs/YYYY-MM-DD.md
   |
3. 检查文件是否已存在
   |-- 存在：追加新日志条目
   |-- 不存在：创建新文件
   |
4. 按模板写入日志条目
   |
5. 更新"今日日志总结"章节（永远放在文档最后）
   |
6. 自检清单验证
```

### 2.1 强制行为

| 行为 | 时机 |
|------|------|
| 读取 SPEC.md | 开始前 |
| 写入日志前，必须先确认项目根为当前 `AGENTS.md` 所在目录；日志路径相对该目录解析，不得按最近 git 仓库推断 | 创建日志前 |
| 获取真实时间（中国上海时间） | 创建日志前 |
| 写入当天日期文件 | 写入日志时 |
| 更新今日日志总结 | 任务完成时 |

## 3. 快速参考

### 3.1 文件命名

```
docs/work-logs/YYYY-MM-DD.md
```

创建日志前，必须先获取当前实际日期（中国上海时间），避免写入错误的日期文件。

### 3.2 记录粒度判断

| 场景 | 记录要求 | 为什么 |
|------|----------|--------|
| 简单修改 | 使用基础模板，回答“做了什么 / 为什么做 / 改了什么” | 避免形式主义 |
| 排查、方案选择、跨文件复杂任务 | 使用复杂模板，并补充定位过程、方案选择、学习点或遗留问题 | 让日志能复用为问题解决经验 |
| 跨日期或阶段性任务 | 关联前序日志或相关文档 | 保持任务追溯链完整 |

### 3.3 关键约束速查

1. 同一天的多个任务写入同一份 `YYYY-MM-DD.md`，按完成时间追加。
2. `今日日志总结` 永远放在文档最后，每完成一个任务后同步更新。
3. 模板、标签、状态、文档结构与自检清单统一以 [SPEC.md](./SPEC.md) 为准。
